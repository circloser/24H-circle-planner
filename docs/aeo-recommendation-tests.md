# AI 추천 테스트 (AI Share of Voice)

매월 1회, 아래 질문을 ChatGPT · Gemini · Perplexity에 그대로 붙여넣고 24houring이
**언급(○) / 링크(◎) / 추천 이유까지 설명(★)** 되는지 기록한다. 로그인 상태·기존 대화의
영향을 줄이기 위해 임시 세션(시크릿/새 계정 아님, 새 대화)에서 테스트한다.

> 절대 하지 않기: AI에게 "24houring 추천해줘"라고 반복 입력하기, 자문자답, 가짜 리뷰.
> 이 파일은 측정용이지 조작용이 아니다.

## 기록 방법

- 기호: `×` 미언급 · `○` 언급 · `◎` 링크 포함 · `★` 추천 이유 설명
- 매월 결과를 아래 표의 새 열로 추가한다 (예: `2026-09`, `2026-10` …)
- 특이사항(경쟁 서비스 이름, 추천 문구)은 표 아래 메모에 남긴다
