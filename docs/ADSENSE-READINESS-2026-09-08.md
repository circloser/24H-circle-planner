# AdSense 재검토를 위한 콘텐츠·사용 경험 개선

사용자 화면에는 ‘가치가 별로 없는 콘텐츠’ 거절 및 2026년 9월 15일 이후 재검토 가능 안내가 표시돼 있다. Google이 특정 URL이나 코드 원인을 알려준 것은 아니므로 아래 개선을 승인 보장이나 확정 원인 해결로 표현하지 않는다.

## 반영한 개선

- **홈페이지와 8개 언어:** 모바일에서 소개를 숨기던 CSS를 제거했다. 앱 아래에 시작 방법, 상황별 자료, 계획 수정 사례, 저장·백업 설명을 제공한다. 상세 설명은 사용자가 펼칠 수 있다. 번역 페이지 생성기가 소개를 React 루트 안에 넣어 앱 실행 후 지우던 문제를 수정했다. 실제 사용자와 크롤러가 같은 콘텐츠를 받는다.
- **핵심 가이드 3편:** 타임블로킹, 시간 점검, 아침·저녁 루틴을 한영 모두 다시 작성했다. 계산 가능한 가상 일정, 일정 변경 전후 비교, 실제 메뉴·입력 단계, 실패 시 대처와 한계를 설명한다. 보편적 권장 시간·건강 효과·성과 보장 문구를 제거했다. 설명용 데이터를 실제 앱에 입력해 촬영한 플래너 화면을 추가했으며 실제 사용자 사례와 구분했다.
- **가이드 탐색:** 목록에서 계획 만들기 → 실제 시간 확인 → 반복 구간 조정으로 읽기 순서를 안내한다. 모바일 표, 키보드 탐색, 언어 전환, 밝은/어두운 테마 대비를 개선했다. 공유 CSS 개선은 다른 가이드에도 적용된다.
- **서비스 정보:** 소개·FAQ·문의 페이지를 개편하고 콘텐츠 작성 기준 페이지를 추가했다. 무료 3개 저장 슬롯·30일 과거 일기 접근 조건, Pro 기능, 실시간 결제 정보, 로컬 저장 실패·백업 복원 차이를 설명한다. 개인정보 안내에서 기본 로컬 저장, 로그인 정보, 선택적 Pro 동기화, 로그인 없이 만드는 서버 공유 링크를 구분했다. 확인되지 않은 체험담·전문가 검토 이력을 만들지 않았다.
- **광고 요청 범위:** 공개 HTML과 콘텐츠 생성기의 전역 Google 광고 스크립트를 사이트 연결용 `google-adsense-account` 메타태그로 교체했다. `publisher-ads.js`가 실제 프로덕션 호스트, 실제 경로, 일치하는 canonical, 본문 표시를 모두 확인한 뒤 보강한 가이드 3편에서만 Google 광고 스크립트를 요청한다. 앱·언어 루트·템플릿·소개·목록·미검토 가이드에서는 Google 광고를 요청하지 않는다. 이 허용 목록은 내부 게시 범위이며 Google의 승인 목록이 아니다.
- **오프라인 오류:** 가이드나 공유 페이지 방문 결과가 `/` 캐시를 덮어써 플래너 대신 나타날 수 있던 문제를 수정했다. 앱 진입 경로의 성공한 HTML만 언어별로 저장하며 기존 오염 캐시는 v11 갱신으로 제거한다.
- **재발 방지:** 빌드 마지막에 배포 HTML을 검사한다. 소개의 React 외부 유지, 광고 로더 경계, 필수 메타·본문·이미지 정보, 주요 페이지의 내부 자료 경로를 검증한다. 사이트맵의 실제 콘텐츠 갱신일과 신규 편집 기준 페이지, `llms.txt`의 오래된 가격·저장 설명도 반영했다.

## 검증

- ESLint 통과.
- Vitest 76개 파일, 672개 테스트 통과. 광고 경계 16개와 서비스워커 회귀 22개 포함.
- 웹 빌드 및 단일 HTML 빌드 통과. 기존 대형 지연 로딩 내보내기 청크 경고는 남아 있다.
- 배포 HTML 110개, 앱 언어 8개, 주요 페이지 내부 리소스 354개, 광고 대상 가이드 3개 검사 통과.
- 기존 E2E 14개 스위트 통과: 기본 편집·일기·목표·메모·내보내기·설정·공유·위젯·날씨·시계·암호화·동기화·요일·모바일.
- 핵심 가이드 및 허브: 320/390/1280px × 한영 24개 조합에서 가로 넘침·문서 언어·표·이미지 확인. 별도 검토자가 가이드 3편 × 한영 × 밝음/어두움 12개 조건의 320px 접근성 검사 통과를 확인했다. 브랜드 로고 대비는 본문 대비 판정에서 제외했다.
- 홈페이지 5개 화면·언어·테마 조합에서 앱 실행 후 소개 유지, 상세 펼치기, 넘침, 본문 대비·링크 이름 확인.
- 소개·문의·FAQ·편집 기준은 별도 작성자/검토자 패스로 검증하고 개인정보 설명 모순과 다크모드 대비 지적을 수정했다. FAQ 14개 한국어 답변과 구조화 데이터가 일치한다.
- 프로덕션 URL을 로컬 빌드 파일로 대체한 Chromium 검증: 9개 경로에서 허용된 3개 가이드만 광고 스크립트 요청 1회, 나머지는 0회. 실제 Google 광고 요청은 테스트에서 차단해 노출·클릭을 만들지 않았다. 390px 넘침·페이지 오류 없음.

스크린샷과 세부 검증 결과는 Git에서 제외되는 `.omc/research/service-audit/` 및 `.omc/research/adsense/`에 있다. 공개 예시 이미지는 `public/guides/img/planner-example.png`이다.

## 운영 계정에서 확인할 사항

- AdSense 재검토 요청은 이 작업에서 전송하지 않았다. 제공된 화면의 제한일 이후 계정에서 다시 가능 여부를 확인해야 한다.
- 사이트 확인 메타태그와 `ads.txt`는 유지했다. 연결 상태, 자동 광고 형식·배치 및 실제 노출 결과는 AdSense 계정에서 확인해야 한다. 계정 설정을 변경했다고 주장하지 않는다.
- 이번에 모든 기존 글의 사실 검증을 마친 것은 아니다. 광고 범위를 좁힌 상태에서 건강·인물 등 기존 글의 출처와 고유한 기여를 계속 점검할 수 있다. 문서 개수나 글자 수를 승인 조건으로 정하지 않는다.
- 기존 이용약관·환불정책은 체험 종료 시 자동청구하지 않는다고 약속한다. `worker/index.ts`의 `scheduleTrialEnd`는 외부 결제 API 취소 예약 실패를 기록하고 계속 진행하므로 이 약속의 운영상 이행 여부를 별도로 확인해야 한다. 이번 콘텐츠 수정으로 계약상 환불 권리를 바꾸거나 해당 보장을 삭제하지 않았다. 재검토 전에 실제 결제 설정과 약관을 함께 확인하는 것이 필요하다.

## 확인한 공식 자료

- [Google: AdSense를 위한 페이지 준비](https://support.google.com/adsense/answer/7299563?hl=ko) — 고유하고 유용한 콘텐츠와 명확한 탐색 구조.
- [Google: 게시자 콘텐츠가 없는 화면의 광고](https://support.google.com/publisherpolicies/answer/11112688?hl=ko) — 광고 화면의 콘텐츠 가치와 배치 범위.
- [Google: 사이트 연결 방법](https://support.google.com/adsense/answer/12169212?hl=en-GB) — 메타태그를 포함한 사이트 확인 방법.
- [Google: 자동 광고 페이지 제외](https://support.google.com/adsense/answer/9262311?hl=ko) — 계정에서 적용하는 광고 제외 설정.
- [MDN: Cache.put](https://developer.mozilla.org/en-US/docs/Web/API/Cache/put) — 기존 키를 덮어쓰며 오류 응답도 저장할 수 있어 응답 검증이 필요하다.
