생활계획표 만들기: 내 상황에 맞는 출발점 찾기

생활계획표는 하루의 활동을 시간 구간으로 배치한 계획입니다. 반복 일과와 오늘의 예외를 구분하고, 필요한 안내와 예시로 이동할 수 있습니다.

원과 표가 각각 보여 주는 것

24시간 원은 하루에서 각 구간이 차지하는 비중을 볼 때 사용할 수 있고, 시간표 보기는 시작·끝 시각을 읽거나 수정할 때 편리합니다. 어느 모양이 모든 사람에게 더 좋은 것은 아닙니다. 작은 화면에서 글자가 겹치면 표로 확인하세요.

가상 예시로 아침 이동이 08:00–09:00에서 08:00–09:20으로 바뀌면 다음 구간에 쓸 수 있는 시간도 20분 줄어듭니다. 원의 경계나 표의 시각을 바꾼 뒤 이웃 구간도 확인하세요. 빈 시간을 만들어 내는 도구가 아니라 이미 있는 제약을 표시하는 도구입니다.

계획을 만드는 순서

다른 사람과 맞춘 약속과 이동·식사·돌봄 등 필요한 시간을 먼저 적습니다. 그 뒤 남은 구간에 할 작업의 범위를 정하고, 불확실한 예상치는 확정 일정과 구분해 메모하세요. 실제 상황이 바뀌면 무엇을 옮길지 다시 선택합니다.

계획은 실제 활동 기록과 다릅니다. 무엇을 했는지 비교하려면 별도 기록 모드나 메모를 사용하세요. 반복 기본형, 오늘 수정본, 날짜별 일기를 구분하면 저장한 내용을 다시 쓸 때 혼동을 줄일 수 있습니다.

저장과 공유 전에 알아둘 점

기본 편집과 PNG·PDF·JSON 내보내기는 가입 없이 사용할 수 있습니다. 무료 저장 슬롯은 3개이고 과거 일기 접근에는 30일 범위가 있습니다. Pro의 현재 가격과 기능은 앱의 안내를 확인하세요.

기본 저장은 브라우저 내부에 남으므로 사이트 데이터 삭제나 기기 변경에 대비해 중요한 데이터는 백업하세요. 선택적 Pro 동기화와 서버 공유 링크는 서버 전송을 사용합니다. 공개할 필요가 없는 일정은 공유 전에 제거하세요.

내 시간표 편집하기

Build a daily routine: choose a starting point

A daily routine assigns activities to time intervals. Separate repeatable commitments from today’s exceptions, then choose a relevant walkthrough or example.

What the circle and the table show

Use the full-day circle to inspect proportions and the table to read or edit exact start and end times. Neither display is best for everyone. If labels are crowded on a small screen, check the table.

If an illustrative journey changes from 08:00–09:00 to 08:00–09:20, the following interval loses 20 minutes. After moving a boundary or editing a time, check adjacent blocks. The tool displays constraints; it does not create additional time.

Build from commitments to choices

First enter commitments agreed with other people and necessary travel, meals or care. Then choose a scope of work for the remaining intervals. Note uncertain estimates separately from fixed appointments. When circumstances change, decide what moves.

Plans are different from observed activity. Use the separate recording mode or notes for comparisons. Distinguish a reusable baseline, today’s edited version and dated diary entries so that you know what you are loading later.

Know what saving and sharing do

Basic editing and PNG, PDF and schedule JSON exports require no account. The free plan has three saved slots and a 30-day past-diary access window. Consult the app for current Pro pricing and features.

Default saving stays in the browser. Back up important data before clearing site data or moving devices. Optional Pro sync and server-hosted share links transmit data to the server. Remove private appointments before publishing a link.
