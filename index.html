Try a time audit
Build, check and revise your first timetable
  1. Place what cannot move. Begin with work, classes, appointments and your own sleep schedule. A template is a worked example, not a recommended lifestyle.
  2. Edit one block at a time. Select a block to change its label; adjust its boundaries to change the time. Switch between full-day, day, night and table views to check the same schedule.
  3. Name an action you can finish. “Review chapter 2 and mark questions” is easier to evaluate than “study harder.” Keep meals, travel and breaks visible too.
  4. Revisit the plan after the day. Note what ran late. Move or shorten the next day's optional task instead of squeezing every remaining hour.

A worked adjustment: the commute runs over

Suppose your plan has travel from 18:00–18:30, dinner from 18:30–19:00 and study from 19:00–20:00. If travel actually ends at 19:00, move dinner to 19:00–19:30 and reduce study to 19:30–20:00. Rename that smaller block “review today's notes.” The example preserves dinner and changes the task to fit the time available; it is not a claim about the ideal study duration.

Saving, backups and the limits of browser storage

Edits are saved in this browser on this device. Check the save indicator after editing. If saving fails, use its retry option or download the emergency backup before closing the page.

Local saving is not a permanent backup. Clearing site data, using a private window or changing browsers can make a local plan unavailable. Export a JSON backup and keep it somewhere you control. PNG and PDF are useful for viewing or printing; JSON is the format for restoring editable data.

Local browser saving is the default. Signing in with Pro enables server sync for supported data; confirm the sync status before relying on another device. Creating a share link also uploads a schedule copy to the server. Previously cached planner functions can work offline; sign-in, sync, weather and other network services still need a connection.

Questions about features, cost and sharing

What is 24Houring?

A browser timetable editor that shows a day as a 24-hour circle. The block sizes show how much of your day each activity occupies. Use the table view when exact start and end times are easier to read as a list.

Is 24Houring free?

Core editing, presets and exports are free without signing up. Free use includes three saved-schedule slots and diary access within the free 30-day window. Optional Pro adds account sync, unlimited saved slots, older diary access, reports and ad removal. Check the upgrade screen for the current price and terms before paying.

Can I switch to a 12-hour (clock) view?

Yes. Full-day, day (06:00–18:00), night (18:00–06:00) and table views display the same planned timetable. Record mode is different: it maintains a separate record of what you actually did, so editing that record does not change your plan.

Can I save or share the timetable I make?

Export PNG or PDF for a visual copy, or JSON for an editable backup. Image sharing depends on your browser and the apps installed on your device. Review the labels before sharing because they may contain personal information.

Which languages are supported?

The app supports English, Korean, German, Japanese, Chinese, French, Spanish and Russian. Some reading resources have fewer translations; their language controls show the versions available.
